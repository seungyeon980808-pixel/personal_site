# 공개 문서함 배포

공유 주소: https://psy.ai.kr/docfinder/

기존 대표 도메인 설정에 따라 https://www.psy.ai.kr/docfinder/ 로 이동한다. 실제 파일과 본문 색인은 이 저장소의 `docfinder/`에 있으며, 외부 문서함을 iframe으로 표시하거나 외부 사이트로 보내는 방식이 아니다. 이전 `/docsbox/` 링크는 새 주소로 이동하며 검색 문자열과 문서 식별 fragment를 보존한다.

2026-10-21 기준 공개 승인된 실제 PDF·HWP 13개와 검색 색인을 배치했다. 원본 스냅샷은 `seungyeon980808-pixel/docfinder`의 `gh-pages` 커밋 `396ac28e6b0da4559a0071637023c6d9739424cd`이다. 문서함은 브라우저에서 검색·미리보기를 처리하며 Render 서버를 호출하지 않는다. 출처와 이용조건은 `docfinder/library/sources.html`에 표시한다.

현재 정적 공개본에는 관리자 로그인, 웹 업로드·삭제, Render 문서함과의 자동 동기화가 없다. 파일 변경에는 공개 스냅샷·목록·본문 색인 재생성과 재배포가 필요하다. Render 관리 화면에서 변경했다고 공개 정적 사이트까지 갱신됐다고 안내하지 않는다.

갱신할 때는 승인된 문서만으로 DocFinder 공개 스냅샷을 생성하고, 배포 허용 파일 검증과 원본 SHA-256 검증 후 `docfinder/`를 갱신한다. 개인 문서함·서버 데이터·환경 변수·비공개 파일은 복사하지 않는다. 새 주소의 목록 13개, 본문 검색, PDF·HWP 미리보기를 확인한다. 기본 홈페이지 파일과 CNAME은 문서함 추가를 위해 변경할 필요가 없다.

## 2026-10-22 공개 자료 추가

공개 자료 6종과 함께 제공된 HWP 서식 2개를 추가해 총 21개 파일을 제공한다. 추가 자료는 서울 중학교 학업성적관리 시행지침, 서울 현장체험학습 길라잡이·운영실무 서식, 중학교 과학실험 안전 매뉴얼, 학교 감염병 예방·위기대응 매뉴얼 제3차 개정판, 아동학대 예방교육 가이드북, 울산 중학교 학적업무 도움자료·서식이다.

각 공식 게시처에서 로그인 없이 받은 원본 바이트를 보존하고, PDF·HWP 페이지별 본문 색인을 추가했다. 기존 13개 파일의 식별자와 원본 SHA-256은 유지했다. 기존 문서와 새 문서에 7개 업무 분류를 지정했으며 발행기관·판본·지역·공식 출처는 공개 출처 안내에서 확인할 수 있다. 울산 학적 자료는 참고용으로 지역을 명시한다.

자료 갱신 범위는 `docfinder/library/`와 공개본의 문서 수·반영 내역 표시다. 관리자 기능 개발 소스를 이 자료 갱신에 함께 포함하지 않는다. 공식 원문은 `catalog.json`의 `sourcePage` 및 신규 파일의 `sourceDownloadUrl`, 배포 원본의 해시는 `manifest.json`에서 추적한다.
