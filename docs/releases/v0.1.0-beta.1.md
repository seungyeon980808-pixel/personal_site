# v0.1.0-beta.1 · 게으른 교사의 작업실 실사용 테스트

만족한 화면과 모션을 기준점으로 고정하고, 실제 사용 중 발견되는 문제를 모으는 첫 베타입니다.

## 접속

https://www.psy.ai.kr/

## 이번 버전

- 맥북과 휴대폰 사이 전환, 잠금 해제 연출, 맥북 로그인 후 전체화면 진입
- 처음 방문할 때 다국어 환영 안내와 둘러보기
- 노치 안에서 자유롭게 움직이는 Claude·GPT·Aside·ExamPool·HwpPalette·5E
- 용수철에 매달린 자기소개와 던질 수 있는 연수 자료 폴더
- 누르는 시간에 따라 강해지는 망치 타격, 화면 균열과 완충 폭발 후 노트북 닫기
- 반복 기기 전환 시 위치가 틀어지는 문제와 휴대폰 확대 하단 보정

## 확인한 내용

로컬 Chromium에서 진입·환영 안내·기기 반복 전환·노치·자료 열기·망치 폭발 복귀 관련 테스트 6개를 통과했습니다.

## 실사용 확인 사항

- 프리릴리즈이므로 아직 안정 버전을 의미하지 않습니다.
- 실제 휴대폰의 터치 조작과 모션 성능, 브라우저별 전체화면 지원을 확인해야 합니다.
- 관리자 Google 로그인과 공개 저장은 운영자 계정으로 실제 확인해야 합니다.
- 잠금 화면의 비밀번호 입력은 입장 연출이며 관리자 인증과 별개입니다.

발견한 문제는 발생 화면, 재현 순서, 기대한 동작, 실제 결과, 브라우저·기기와 함께 모은 뒤 다음 작업에 반영합니다.
