# 모바일 모션 처리 비용 개선

기능 및 이미지 자산은 유지했다. 노치 위치 갱신을 left/top에서 translate로 바꾸고 컨테이너 크기 읽기를 쓰기보다 먼저 수행한다. 노치와 물리 모션은 숨겨졌거나 탭이 비활성일 때 프레임 예약을 중단한다. 용수철의 201개 표본에 대한 고정 삼각함수 계산은 초기화 시 한 번 수행한다.

휴대폰 진입의 기존 1.8초 모션이 완료되는 경계에서 전체화면을 요청한 뒤 작업실로 전환한다. 맥북의 기존 전체화면 요청 시점은 유지했다. 브라우저가 요청을 거절하면 기존 화면 안에서 진입을 완료한다. 아이폰에서 주소창 제거를 보장하지 않는다.

## 비교 측정

Chromium, 390×844, CPU 4배 감속. 각 버전에서 입구 진입 후 환영 안내를 넘긴 뒤 3초의 활성 작업실을 측정했다. 이전 버전은 HEAD의 index.html, 개선 버전은 새 빌드다. 한 쌍의 비교이며 실제 휴대폰 측정이나 평균 FPS 측정은 아니다.

| 지표 | 이전 | 개선 |
| --- | ---: | ---: |
| LayoutCount | 2166 | 360 |
| RecalcStyleCount | 2166 | 360 |
| TaskDuration | 0.588초 | 0.495초 |
| LayoutDuration | 0.0616초 | 0.0180초 |

기존 두 iframe 로딩 구조와 그래픽 필터는 그대로 유지했다. 네트워크 로딩 및 실제 모바일 GPU 병목은 이번 측정으로 해소됐다고 단정하지 않는다.
